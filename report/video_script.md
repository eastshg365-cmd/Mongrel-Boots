---

## 1. The Evolution（0:15 – 0:45）
**画面**: 切换到 Assignment 1 的 Mongrel Boots 原站截图 → Figma 草图 → 最终设计对比

> "In Assignment 1, I identified Mongrel Boots as an underperformer. The original site lacked visual hierarchy, had no e-commerce flow, and offered no smart search or AI recommendations.

> My redesign journey started with inspiration and mood boarding — establishing yellow, black, and white as the core palette to reflect the brand's tough, functional identity.

> I then went through five rounds of divergent sketching, referencing competitors like R.M. Williams and Tony Bianco, before landing on a bold, modular layout with sharp angular forms — a deliberate design choice to match the brand's rugged outdoor positioning."

---

## 2. Design Rationale（0:45 – 1:15）
**画面**: Figma prototype 演示 mobile 端 → 展示 Art Direction 1（最终选定方案）

> "Every design decision was intentional. The angular square format — instead of rounded corners — directly communicates the brand's toughness and practicality.

> The three-color system creates strong contrast, satisfying WCAG accessibility requirements for color contrast ratios. All interactive elements have clear visual states distinguishing clickable from non-clickable items.

> During usability testing, I discovered critical issues: the Shop Now button wasn't working, there was no size or model selector, and the checkout had no confirmation state. I fixed all of these in the final prototype — making the full shopping flow functional and accessible.

> For desktop adaptation, I maintained the same visual language but reorganised the grid for wider viewports, ensuring responsive design across devices."

---

## 3. Technical Implementation（1:15 – 1:45）
**画面**: 切换到 VS Code / 代码编辑器，展示 HTML/CSS 代码结构

> "For implementation, I chose HTML5 with semantic elements — using nav, main, section, and article tags — not just for structure, but because semantic HTML directly improves screen reader accessibility.

> Coding the site gave me a completely different understanding of design. Things that looked simple in Figma — like a product grid that shifts from 2 columns on mobile to 4 on desktop — required thinking in CSS Flexbox and Grid, and understanding breakpoints.

> This process made me realise that designing with implementation in mind produces better, more buildable designs. I started making decisions in Figma based on how they would actually be coded."

---

## 4. Collaboration（1:45 – 2:05）
**画面**: 展示课堂截图、或者模拟 mentor 反馈笔记

> "Throughout this project, mentor feedback was invaluable. During the weekly check-in, my mentor pointed out that my initial prototype used inconsistent interactive states — some buttons were clickable, some weren't, with no visual difference.

> This feedback directly led me to define a unified interaction design system: earthy tones for active states, white outlines for passive ones.

> I also incorporated feedback on the homepage — originally too image-heavy — by restructuring it to lead with product categories and a clear call-to-action, improving the user flow significantly."

---

> [Point to repo URL on screen]

> Each commit message describes what changed and why, making my workflow transparent and traceable. The repository includes a README with setup instructions, design decisions, and links to my Figma prototype."

## 结尾（2:25 – 2:35）

> "This project taught me that great design is not just visual — it's systematic, accessible, and buildable. Thank you."
